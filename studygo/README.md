# StudyGo

StudyGo is a student-focused study planning app built with Next.js.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the landing page.
The sign-in experience is at [http://localhost:3000/login](http://localhost:3000/login).

## Sign-in status

The login page currently presents a Google sign-in entry point, but OAuth is
not connected yet. A Google OAuth client and server-side authentication flow
must be configured before users can sign in.
